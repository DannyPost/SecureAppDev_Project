# Student IT Helpdesk

A web application for the Secure Application Programming project at
National College of Ireland, built with Python, Flask and SQLite3.

## Planned features

- Students can sign in, create a support ticket, search their own tickets
  and add comments to them.
- Support agents can reply to tickets and update their status.

## Branches

- Main: shared project files and configuration manual.
- Secure: the helpdesk implementation with security controls.
- Insecure: the comparison implementation used in the assessment.
